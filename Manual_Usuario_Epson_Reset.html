Epson Reset

Adjustment Program / Waste Ink Pad Counter Reset — RAW 1.0.1.1

L1210L3210L3250L3251L3260L5290 RAW

1. Introduccion

Bienvenido al Manual de Usuario de la aplicacion Titulo Epson Reset. Esta aplicacion restablece el contador de almohadilla de tinta residual cuando aparece "Se requiere servicio" o parpadean las luces de tinta y papel.

Integra todas las versiones que soporta la aplicacion: L1210, L3210, L3250, L3251, L3260, L5290 RAW en un solo documento.

3. Requisitos

  • Windows 7/8/8.1/10/11
  • Cable USB bueno a puerto USB 2.0 (no hub, no WiFi)
  • Impresora encendida con papel
  • Archivos: AdjProg.exe + apdadrv.dll + StrGene.dll juntos
ADVERTENCIA: Use solo USB. No desconecte durante Check/Initialize. Ejecute siempre como Administrador.

4. Procedimiento Paso a Paso

PASO 1: Conexion + Administrador

Para usar la aplicacion debes conectar el cable USB de tu impresora a la computadora. Despues hay que ejecutar la aplicacion como Administrador (clic derecho > Ejecutar como administrador).

PASO 2: Select + Modelo + Puerto

Paso 2: Presionar Boton Select y elegir el modelo de Impresora Correspondiente. En Puerto hay que elegir USB00x. Pulse OK.

PASO 3: Particular Adjustment Mode

Paso 3: Pulsar sobre el boton Particular Adjustment Mode.

PASO 4: Waste Ink Pad Counter

Paso 4: seleccionar Waste Ink Pad Counter y pulsar OK.

PASO 5: 3 Casillas + Check

Paso 5: seleccionar las 3 casillas y pulsar sobre el boton Check. Esperar a que muestre el porcentaje de vida.

PASO 6: 3 Casillas + Initialize + Apagado

Paso 6: Vuelve a seleccionar las 3 casillas y pulsa sobre el boton Initialize. Una vez que hayas pulsado aparecera un nuevo cuadro de dialogo: Presiona Ok y despues apaga tu Impresora, despues pulsa sobre Finish y Listo.

RESULTADO: Al hacer Check de nuevo debe mostrar 0.00%. Las luces dejan de parpadear.

5. Solucion de Problemas

  • No aparece USB: cambie cable/puerto, reinstale driver, ejecute como admin.
  • Se cierra solo: use AdjProg_Win10_x64ready.exe o .bat lanzador.
  • Communication error: modelo incorrecto en Select.
  • Pide key: esta edicion RAW 1.0.1.1 no pide key.
